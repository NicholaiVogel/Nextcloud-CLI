# Code of Conduct

This project exists to build useful software for people who run their own
tools. The community around it should be practical, respectful, and safe to
participate in.

## Expected behavior

- Be direct without being cruel.
- Assume good intent until there is evidence otherwise.
- Keep criticism focused on the work, not the person.
- Respect different levels of experience.
- Give people enough context to understand your feedback.
- Do not pressure anyone to disclose private infrastructure, credentials, or
  personal information.

## Unacceptable behavior

- Harassment, threats, stalking, or intimidation.
- Slurs or demeaning language.
- Sexualized attention or comments in project spaces.
- Publishing private information without consent.
- Sharing credentials, tokens, private server URLs, or private file contents.
- Bad-faith disruption of issues, pull requests, discussions, or reviews.

## Maintainer responsibilities

Maintainers may remove comments, close issues, reject pull requests, block
participants, or take other reasonable action when behavior harms the project
or its contributors.

Maintainers should apply this policy consistently and explain moderation
decisions when doing so does not expose private information or create more
harm.

## Reporting

If you see behavior that violates this code of conduct, contact the maintainer
privately when possible. If no private contact is available, open a minimal
public issue asking for a private moderation contact. Do not include private
personal information in a public issue.

## Scope

This code applies in project spaces, including issues, pull requests,
discussions, reviews, and community channels connected to the project.
